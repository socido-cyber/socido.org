Language + X Programs (Theatre & Dance)

We organize free language classes and "Language + X" programs—pairing language learning with creative arts like Language + Theatre and Language + Dance.

By integrating movement, acting, music, and performance, we kindle genuine curiosity and enthusiasm in children and teens for learning new languages and embracing new cultures.
